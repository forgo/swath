# Swath UDF ABI v1 (normative)

The wire contract between the Swath tile engine (host) and a `run_udf`
WASM module (guest), per [ADR 0018](../decisions/0018-run-udf-sandboxed-wasm.md).
Manifest-v1 discipline applies: this document is **versioned** (`"abi": 1`),
readers are **deny-unknown** (a header field or export this version does not
define is a registration error, never ignored), the serde shapes are
**snapshot-pinned** in the executor's tests, and a changed contract is a new
`v2.md` superseding this file — v1 is never edited incompatibly.

## Module requirements

A module is accepted at registration iff:

1. it imports **nothing** (no functions, memories, globals, or tables — the
   zero-import rule; determinism is structural),
2. it exports exactly the four symbols below with these signatures,
3. it declares ≤ 64 MiB of linear memory.

## Exports

| Export | Signature | Contract |
|---|---|---|
| `swath_udf_abi` | `() -> i32` | Returns `1`. Any other value: rejected at registration. |
| `swath_udf_output_planes` | `(i32 input_planes) -> i32` | The number of output planes for a given input count; `<= 0`: rejected. Pure — called once at registration per declared input arity and pinned. |
| `swath_udf_alloc` | `(i32 len) -> i32` | Returns a guest pointer to `len` writable bytes (the host writes the request buffer there). `0`: allocation failure, the run errors. |
| `swath_udf_run` | `(i32 ptr, i32 len) -> i64` | Executes over the request buffer at `ptr..ptr+len`; returns `(out_ptr << 32) \| out_len` naming the response buffer, or `0` on guest-declared failure. |

## Request buffer (host → guest)

```text
[u32 header_len (LE)] [header_len bytes: JSON header] [payload]
```

Header (JSON, UTF-8, deny-unknown):

```json
{
  "abi": 1,
  "width": 256,
  "height": 256,
  "planes": 2
}
```

Payload, per plane, in header order, tightly packed:

- `width × height` **`f64` little-endian** sample values (row-major, the
  `WarpedBuffer` convention: invalid pixels hold `0.0`),
- `width × height` **`u8`** validity flags (`1` valid, `0` invalid).

## Response buffer (guest → host)

Same shape: `[u32 header_len][JSON header][payload]`, with the header

```json
{ "abi": 1, "planes": 1 }
```

and `planes` equal to the pinned `swath_udf_output_planes` answer; payload =
per-plane `f64` values + `u8` validity as above, `width`/`height` unchanged
(v1 is dimension-preserving; halo/resampling UDFs are a v2 reopen condition).

## Host post-conditions (enforced, not requested)

- Output validity is **ANDed** with input validity (the union of all input
  planes' masks): a UDF can invalidate pixels, never fabricate validity.
- Non-finite outputs where the guest claims validity are canonicalized to
  invalid (NaN/±∞ never reach the encode stage as "data").
- Fuel and the 250 ms epoch deadline (ADR 0018) bound the `swath_udf_run`
  call; either tripping is a per-tile UDF error carried on the Trace.

## Versioning

`swath_udf_abi` returning anything but `1`, an unknown header field, a
header `abi` ≠ 1, or a payload length disagreeing with the header are all
loud registration/run errors. The next incompatible contract is
`docs/udf-abi/v2.md` + `swath_udf_abi` = 2; hosts may support both during a
deprecation window, never a silent blend.
