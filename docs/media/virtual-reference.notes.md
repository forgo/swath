Precision note: "byte-identical" is used in two committed senses and the SVG keeps them
separate — (a) manifest **byte-range equivalence** between the Rust referencer and the
VirtualiZarr reference (identical arrays, chunk grids, per-chunk offset+length, codecs; the
two JSON files differ by a trailing newline, 201,585 vs 201,584 bytes), and (b) **pixel**
byte-identity of `read_window` output against h5py (SHA-256). The chunk-grid drawing is
schematic (a real VNP09GA array is e.g. 3232×3200 with 1616×1600 chunks); the highlighted
"only touched chunks" behavior is the tested contract, not a count.
